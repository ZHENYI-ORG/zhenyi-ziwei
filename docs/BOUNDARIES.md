# 已知边界与口径

本页说明排盘结果在哪些条件下需要额外核对。

- **历法范围**：公历日期从 1900-01-31 到 2100-12-31。1900-01-31 之前无法从内置农历表转换。网页的年份选择仍显示 1900 年，输入较早日期时引擎会报错。
- **朔的日界**：2057-09-28 和 2097-08-07 的朔接近午夜，历算精度与不同历表取舍可能造成一天差异。
- **城市经度**：内置城市经度为近似值，通常保留到 0.1° 左右。时辰接近交界时，应核对出生地的准确经度和记录时间。
- **夏令时**：自动判断仅覆盖中国 1986—1991 年历史夏令时。其他地区如需校正，应明确传入 `dst`。
- **流派口径**：四化、闰月、晚子时和部分杂曜有不同取法。网页提供设置；API 参数见 [API.md](API.md)。对照其他排盘软件前，先统一这些设置。
- **解读性质**：格局与断语是可检查的规则文本，不等于事实预测。涉及健康、财务和法律事项时，不应以命盘代替专业意见。

若发现差异，请附上可复现的输入、期望结果和参考来源，按 [贡献指南](../CONTRIBUTING.md) 提交 issue。
